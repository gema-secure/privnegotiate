# 标注规范：菜品—过敏原三态

版本 1.0.0，适用于 `datasets/allergen_tristate` 下的全部数据。任何新增或修改必须遵守本规范；修改判定规则属于契约变更。

## 1. 三态定义

| 状态 | 含义 | 判定要求 |
| --- | --- | --- |
| `CONTAINS` | 已知含该过敏原 | 配料本身即致敏原，或权威标准/成分表/配料表明确列出该致敏原 |
| `NOT_CONTAINS` | 已知不含该过敏原 | 权威成分表能确证该配料不含该致敏原，且不存在配方变体或交叉接触 |
| `UNKNOWN` | 无法确证 | 复合调料、加工食品、配方不固定、来源未覆盖、交叉接触不可排除 |

`UNKNOWN` 不是「大概不含」，也不是「待补充」。它是数据集中与 `CONTAINS`、`NOT_CONTAINS` 同等的一等状态。

## 2. 证据等级

| 等级 | 证据类型 | 示例 |
| --- | --- | --- |
| A | 官方标准、政府/权威机构数据库、单一食材成分表 | GB 7718、EU 1169/2011、USDA FDC、中国食物成分表、香港食安中心 |
| B | 公开包装食品数据库、品牌官方配料表 | Open Food Facts、酱油/蚝油/火锅底料包装配料表 |
| C | 菜谱、烹饪文献、通用配方推定 | 地方菜谱中的配料组成 |
| D | 无直接来源，仅价格或演示信息 | 市场参考价 P1 |

菜品 `credibility` 取配料链中最低一级：A > B > C > D。价格来源不参与过敏原证据可信度。

## 3. 配料级判定流程

对每个「配料 × 过敏原」依次执行：

```text
1. 该配料本身是否就是致敏原？
   是 -> CONTAINS
   否 -> 2

2. 权威成分表/标准是否明确列出该配料含该致敏原？
   是 -> CONTAINS
   否 -> 3

3. 该配料是否为复合调料、加工食品、配方不固定项？
   是 -> UNKNOWN
   否 -> 4

4. 是否存在配方变体、共线生产、交叉接触或来源未覆盖？
   是 -> UNKNOWN
   否 -> 5

5. 权威成分表是否能确证该配料不含该致敏原？
   是 -> NOT_CONTAINS
   否 -> UNKNOWN
```

第 5 步是唯一允许判 `NOT_CONTAINS` 的出口。拿不到确证时，必须回到 `UNKNOWN`。

## 4. 配料级规则

### 4.1 单一食材

- 新鲜蔬菜、水果、肉类、禽类、蛋类、乳类、鱼类、甲壳类、软体动物、谷物、薯类等，按单一食材处理。
- 本身即致敏原的，直接 `CONTAINS`：虾→甲壳类、鱼→鱼类、鸡蛋→蛋类、牛奶→乳、花生→花生、芝麻→芝麻、小麦粉→麸质、豆腐→大豆。
- 本身不是致敏原的，且成分表能确证的，记 `NOT_CONTAINS`，例如大米、土豆、黄瓜、猪肉、牛肉、鸡肉。
- 不得因为「它是蔬菜」就跳过成分表；默认 `NOT_CONTAINS` 只适用于已在 `evidence` 中写明单一食材依据的配料。

### 4.2 复合调味料

- 酱油：大豆 + 小麦 → `soy=CONTAINS`、`gluten=CONTAINS`；焦糖色可能带亚硫酸盐 → `sulphite=UNKNOWN`。
- 蚝油：蚝汁 + 小麦粉 → `mollusc=CONTAINS`、`gluten=CONTAINS`；大豆与亚硫酸盐不确定 → `UNKNOWN`。
- 豆瓣酱（郫县）：蚕豆 + 小麦粉 → `gluten=CONTAINS`；大豆不是主要配料 → `soy=NOT_CONTAINS`；亚硫酸盐 → `UNKNOWN`。
- 黄豆酱：大豆 + 小麦 → `soy=CONTAINS`、`gluten=CONTAINS`。
- 咖喱块：常含小麦粉、乳，可能含芥末、芹菜 → 对应项 `UNKNOWN`。
- 火锅底料：配方差异极大，除羽扇豆外多项 `UNKNOWN`。
- 鸡精、高汤/浓汤宝、烧烤腌料、辣椒酱、沙拉酱：按包装标签能确证的记 `CONTAINS`，其余可能项记 `UNKNOWN`。

### 4.3 加工肉制品

腊肉、香肠、火腿可能含填充物（麸质、大豆）、乳制品与亚硫酸盐；无法从通用配方确证时，四项均记 `UNKNOWN`。

### 4.4 油脂

- 花生油、芝麻油：按标签保守记 `CONTAINS`。精炼油蛋白残留很低，但标签与医学建议并不完全一致；本数据集选择保守口径。
- 普通植物油（菜籽油、大豆油、玉米油等）不单列；若菜品使用花生油或芝麻油，必须在 `ingredient_ids` 中列出。
- 共用炸油：无法排除麸质、甲壳类、鱼类、蛋、乳、大豆、花生、软体动物的交叉接触，对应项记 `UNKNOWN`。

### 4.5 酒类

- 啤酒：大麦麸质 → `gluten=CONTAINS`；亚硫酸盐 → `sulphite=CONTAINS`。
- 红酒：亚硫酸盐 → `sulphite=CONTAINS`。
- 料酒、米酒：可能含小麦，且可能含亚硫酸盐 → 两项 `UNKNOWN`。
- 酒类澄清剂（蛋清、鱼胶、明胶）未建模，写入已知局限。

### 4.6 坚果、种子与交叉反应

- 腰果、核桃、杏仁、松子 → `tree_nut=CONTAINS`。
- 花生独立于坚果，记 `peanut=CONTAINS`。
- 芝麻独立，记 `sesame=CONTAINS`。
- 板栗、莲子、椰子不在欧盟 14 类「坚果」清单内，记 `NOT_CONTAINS`，并在备注中说明；这不等同于对个体的临床安全判断。

### 4.7 小麦淀粉与澄面

小麦淀粉（澄面）经过精制，理论上可低于麸质阈值，但不同产品工艺差异大，且标签口径不一；无法确证时记 `gluten=UNKNOWN`，不得直接记 `NOT_CONTAINS`。

### 4.8 燕麦与格兰诺拉

燕麦常与小麦共线，格兰诺拉可能含坚果、花生、乳、芝麻；对应项记 `UNKNOWN`。

## 5. 菜品级聚合

菜品状态由配料状态按三值逻辑聚合：

```text
if 任一配料 == CONTAINS:
    菜品 = CONTAINS
elif 任一配料 == UNKNOWN:
    菜品 = UNKNOWN
else:
    菜品 = NOT_CONTAINS
```

优先级：`CONTAINS > UNKNOWN > NOT_CONTAINS`。

### 5.1 示例

麻婆豆腐配料：豆腐、豆瓣酱、酱油、辣椒、葱姜蒜。

```text
豆腐     -> soy=CONTAINS
豆瓣酱   -> gluten=CONTAINS, sulphite=UNKNOWN
酱油     -> soy=CONTAINS, gluten=CONTAINS, sulphite=UNKNOWN
辣椒     -> 全部 NOT_CONTAINS
葱姜蒜   -> 全部 NOT_CONTAINS
```

聚合结果：

```text
gluten     = CONTAINS（豆腐? 否；豆瓣酱/酱油 是）
soy        = CONTAINS（豆腐/酱油）
sulphite   = UNKNOWN（豆瓣酱/酱油）
其他 11 项 = NOT_CONTAINS
```

`basis_ingredient_ids` 记录触发 `CONTAINS` 或 `UNKNOWN` 的配料，便于审计。

### 5.2 冲突处理

- 两个来源冲突时，取更保守的状态：`CONTAINS` 优先于 `UNKNOWN`，`UNKNOWN` 优先于 `NOT_CONTAINS`。
- 不得用「多数来源说不含」覆盖一个明确的 `CONTAINS` 来源。
- 不得用「某菜通常不放」推断 `NOT_CONTAINS`；没有配料证据就是 `UNKNOWN`。

## 6. 交叉接触

- 只在有明确共享设备/工艺线索时建模，例如共用炸油。
- 共用炸油会影响麸质、甲壳类、鱼类、蛋、乳、大豆、花生、软体动物；对应项记 `UNKNOWN`。
- 案板、刀具、烤架、油锅过滤、服务分餐等环节未建模；写入已知局限，不得假装已覆盖。
- 交叉接触不是 `CONTAINS` 的确证，也不是 `NOT_CONTAINS` 的理由。

## 7. 人工复核标记

- `manual_review=1`：该行存在人工复核/修正，或至少一个 `UNKNOWN`，或配料链中有复合调料/加工食品/交叉接触。
- `manual_review=0`：该行完全由规则从配料表推定，且没有 `UNKNOWN`。
- 该标记只表示数据质量与不确定性，不表示临床验证或官方认证。
- 人工修正必须保留 `note`，说明改了什么、依据是什么；不得直接改结果而不留痕。

## 8. 价格字段

- `price_cents` 是演示用参考价，来源 `P1`，可信度 D。
- 价格不是过敏原证据，不参与 `credibility` 计算。
- 生产环境应替换为用户导入的真实菜单价格；不得把 P1 当作市场价格数据引用。

## 9. 场景抽样与规模

- 单次协商候选数必须为 13–30 项。
- 每个场景的候选池必须 ≥ 13 项；目标数必须在 13–30 之间。
- 抽样使用固定种子 `20261110`，按「新增（过敏原, 状态）覆盖 > 新菜系 > 新价格带」贪心选取，平局按固定洗牌顺序决定。
- 不得为了凑数把同一道菜重复放入同一场景。
