# P1-01 骨架与健康检查

把下面整段贴进码道对话框；模式选 **规范开发 / Spec-Driven**（先出计划，再落代码）。

---

你是本项目的代码智能体。项目：私密协商器——3–6 人在预算和数量约束下，私密填写偏好、逐轮收窄、由程序算出一套组合方案。

本轮只做最小可运行骨架，**不要实现任何业务算法**：

1. 在当前工作区生成 FastAPI 骨架（Python 3.11）：
   - `app/main.py`
   - `app/core/config.py`
   - `app/api/health.py`
   - `app/db/session.py`
   - `app/cache/redis.py`
   - `tests/test_health.py`
2. 提供 `GET /healthz`，返回：
   `{"app":"ok","db":"ok|error","redis":"ok|error","version":"0.1.0"}`
   DB / Redis 连不上时返回对应 `error` 字段，**不要抛 500**。
3. 配置全部来自环境变量（`DATABASE_URL`、`REDIS_URL`、`APP_ENV`），提供 `.env.example`；**不得硬编码任何密钥**。
4. 依赖只用：fastapi、uvicorn、sqlalchemy、pymysql、redis、pydantic-settings、pytest。不要引入其他库。
5. 全部代码带类型注解；不写业务逻辑，不建业务表。

请先输出：文件树 + 实施计划 + 每个文件的职责，等我确认后再逐个生成。
