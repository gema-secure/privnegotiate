# CodeArts 码道使用证据库

状态：**空模板，尚无真实记录**（2026-11-15 建立）。

本目录用于留存码道 CodeArts 在「需求理解 → 代码生成 → 项目构建 → 问题修复 → 部署上线」五环节中的真实使用证据。只记录实际发生过的操作；没有发生的环节保持空白，不得用推测、截图拼接或事后补写冒充。

## 目录约定

```text
evidence/codearts/
├─ README.md
├─ _template/                 # 空白模板，不要直接改
│  ├─ 01-任务说明.md
│  ├─ 02-输入提示词.md
│  ├─ 03-输出结果.md
│  ├─ 04-人工结论.md
│  └─ 05-验证记录.md
└─ YYYYMMDD-环节-序号/        # 每次真实使用建一个目录
   ├─ 01-任务说明.md
   ├─ 02-输入提示词.md
   ├─ 03-输出结果.md
   ├─ 04-人工结论.md
   ├─ 05-验证记录.md
   └─ assets/                 # 截图、导出文件
```

命名示例：`20261120-代码生成-01/`、`20261121-项目构建-01/`、`20261122-部署上线-01/`。

## 使用规则

1. 一次任务一个目录，五部分齐全；缺哪部分就在该文件写「未产生」，不要删文件。
2. 时间、执行人、码道版本、关联 commit 必须真实；关联 commit 填短哈希。
3. 提示词保留原文，不改写、不美化；多次追问按顺序编号。
4. 输出结果保留原始导出或截图，注明是完整采纳、部分采纳还是未采纳。
5. 人工结论必须写清「改了什么、为什么改、谁确认」；安全相关字段不得由模型直接放行。
6. 验证记录写可复现的命令与结果；测试数量、构建产物以当时输出为准。
7. 包含密钥、令牌、真实个人信息的截图不得入库。

## 当前缺口

- 代码生成、项目构建、部署上线三环节尚无真实记录。
- 需求理解环节仅有仓库索引，未导出对话。
- 问题修复环节有真实缺陷与回归结果，可将当次审查记录补入。
